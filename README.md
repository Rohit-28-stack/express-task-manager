# File-Based Task Manager

A simple CRUD application built using Node.js, Express, and EJS.

# Features
- Create tasks (stored as files)
- View all tasks
- Read task content
- Edit filename
- Delete task

# Tech Stack
- Node.js
- Express.js
- EJS
- Tailwind CSS
- File System (fs module)

# How to run
```bash
npm install
node app.js
